# Fotos reais

Coloque aqui os arquivos com esses nomes exatos — os componentes já estão
prontos para usá-los automaticamente assim que existirem (sem precisar tocar
em código):

| Arquivo | Onde aparece |
|---|---|
| `hero.jpg` | Home — foto grande ao lado do título |
| `sobre.jpg` | Página `/sobre` |
| `cartas-vestibulando.jpg` | Capa do livro em `/produtos` |

Até o arquivo existir, o site mostra o placeholder editorial no lugar.
